SECURITY ADVISOR

Apne device ki security check karo

✅ 1. Device Security Checklist

  • Screen lock ON hai (PIN/Pattern/Password)
  • Auto-update ON hai
  • Find My Device ON hai
  • 2-Factor Authentication ON hai
  • Unknown sources OFF hai
  • VPN use karte ho public WiFi par

🔐 2. Password Security

  • Har account ka alag password
  • Password Manager use karo (Bitwarden)
  • 12+ characters, mix of letters/numbers/symbols
  • Kabhi kisi ko password mat batao
  • Har 6 mahine mein change karo

📱 3. App Security

  • Sirf Play Store / App Store se install karo
  • App permissions check karo (Camera, Location, Contacts)
  • Purane apps uninstall karo
  • Kisi bhi app ko Accessibility permission mat do
  • Unknown APK files mat install karo

🚨 4. Emergency Actions

  • Fraud hua? Call 1930 (Cyber Helpline)
  • Report: cybercrime.gov.in
  • Bank ko turant inform karo
  • SIM block karwao (agar SIM fraud)
  • Screenshots rakho (evidence ke liye)

🔗 5. Safe Browsing Tips

  • URL check karo before login
  • HTTPS (padlock) dekho
  • Public WiFi par banking mat karo
  • Browser extensions update rakho
  • Pop-up ads par click mat karo
