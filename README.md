# CyberDefender OM

**AI-Powered Cybersecurity & Online Fraud Prevention Platform**

---

## About

CyberDefender OM is an advanced AI-powered cybersecurity platform that protects users from phishing URLs, fake emails, fraud messages, malicious code, and AI-generated images.

---

## Features

- URL Scanner - Detects phishing URLs using ML
- Fake Email Detector - Identifies fraudulent emails
- Fraud Message Scanner - Detects scam SMS/WhatsApp
- Code Scanner - Finds SQL injection, XSS
- AI Image Detector - Flags AI-generated images
- User Login/Signup - Secure authentication
- Complaint System - Report online fraud
- Feedback System - User reviews

---

## Tech Stack

- Backend: Python, Flask, SQLAlchemy
- AI/ML: Scikit-learn, Pandas, NumPy
- Frontend: HTML5, CSS3, JavaScript
- Database: SQLite
